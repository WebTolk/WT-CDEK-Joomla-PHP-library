# Последнее уточнение оператора: прототип на joomla.local

Этот scope supersedes предыдущий план переноса поля в библиотеку до её отдельного релиза. Библиотека WT-CDEK-Joomla-PHP-library изучена без изменений (source1.3.1; установленная на joomla.local1.3.2). Названный сначала rcsh.local отменён последующим уточнением: только joomla.local.

watchfield — общий механизм для полей тарифа и ПВЗ: одиночное имя поля сохраняется для прежнего tariffinfo; именованная JSON-карта задаёт parameter => Joomla Form field name. Карта ПВЗ использует ключи zip/city. XML zip="410000" и city="Саратов" выбирают literal mode; любые явно заданные zip/city имеют приоритет над watchfield, включая пустые значения. В literal mode watchfield полностью игнорируется и не создаёт зависимостей. Без literal attributes применяются значения и события указанных полей формы. Идентификаторы и names разрешаются через настоящий Form, без предположения о префиксе jform. Dot-separated field paths позволяют указать другую fields group.

Текущий прототип размещён в WT CDEK JoomShopping: отдельный Watchfield PHP resolver и общий JS watcher; оба поля используют его. Временный WtsmcdektariffinfoField наследует данные/layout установленной библиотеки, но не запускает её прежний inline watcher. Новый механизм обеспечивает одинаковую семантику scalar и map watchfield. Классы/JS остаются в текущем расширении до подтверждённой проверки и дальнейшего отдельного переноса в библиотеку по поручению оператора.

Оператор разрешил отработку на локальном стенде: точечное staging файлов с приватной резервной копией, настоящие administrator forms и браузерные проверки. Временные XML probe fields ставятся только в локальную копию params.xml и после проверки удаляются. Настройки магазина не сохраняются; заказов, оплат, CDEK shipment mutations, сторонних сайтов, commit/push/package release нет. Разрешены read-only lookup населённых пунктов/ПВЗ для проверки списка. Library source/installed library не редактируются. Версии обоих продуктов сохраняются.

Проверки: native fields resolution и rendering, map зависимости, literal precedence при конфликтующем watchfield, city-only/zip-only/empty literal modes, смена city/zip и устаревшие ответы, сохранённая selection и несколько одновременных полей, scalar/map tariff info, scoped fileset полностью покрывает payload. Локальная runtime acceptance отдельно от release/package readiness; paused security audit не возобновляется.

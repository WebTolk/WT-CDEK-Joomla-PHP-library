# WT CDEK 1.4.0-dev

Добавлено нейтральное поле Deliverypoints для ПВЗ и постаматов, включая пункты только выдачи. XML point_type/is_reception/is_handout управляют фильтрами; city/zip/fias_guid по наличию имеют приоритет над наблюдением. FIAS UUID запрашивает пункты непосредственно.

Добавлен общий Watchfield WebAsset: автоматический поиск зависимостей Joomla Form, несколько потребителей, разные формы, repeatable subform, Script Options и AJAX. Изменение источника немедленно сбрасывает устаревший выбор; запросы имеют debounce, CSRF, отмену и защиту от гонок. Кнопка обновления ПВЗ удалена по уточнённому требованию.

Публичный Tariffinfo переведён с inline JS на WebAsset, каталог — в Joomla Script Options. Существующие type, watchfield и alias tariff_field сохранены; JS-тексты экспортирует WatchfieldAssetItem. Tarifflist продолжает работать как стандартный сгруппированный список.

Миграция: существующий XML Tarifflist/Tariffinfo оставьте без изменений. В пользовательском переопределении tariffinfo layout добавьте `$watchfield_attributes` на контейнер `.wt-cdek-tariffinfo-field`. Для нового Deliverypoints используйте `addfieldprefix="Webtolk\Cdekapi\Fields"`; donor-типы JoomShopping не являются публичным API этой библиотеки. Поиск по fias_guid не принимает city_uuid СДЭК.

Версия minor: новые обратно совместимые возможности относительно публичной 1.3.2, prerelease `-dev`. Четыре manifest синхронизированы. Сборка только локальная; публикация dev на GitHub не выполнялась.

Проверки: **39 Chrome CDP E2E**, **83/84/84** offline checks Joomla 4/5/6, **40 PHP lint**, три JS syntax checks и audit ZIP/settings. [Документация полей](../../.docs/index.md) · [полная приёмка](../reports/2026-10-12-watchfield-140-dev-verification.md).

# WT Cdek library package 1.4.0 — пакет для ручной проверки

Версия конфигурации сборки, пакета, библиотеки и обоих плагинов — 1.4.0. Локальная сборка завершена; публикация и установка не выполнялись.

## Что нового

RU/EN PKG_LIB_WTCDEK_WHATS_NEW содержат четыре коротких пользовательских пункта: выбор ПВЗ/постаматов по городу и индексу, обновление списка при изменении адреса, обновление информации о тарифе и совместимость с cookie-баннерами. Технические названия классов, WebAsset и токены в тексте отсутствуют.

Файловые PHP/JS док-блоки используют глобальный шаблон PF; в ZIP версии метаданных раскрыты в 1.4.0. Настройка textExtensions включает JS; .playwright-mcp исключён из пакета.

# Watchfield / 1.4.0-dev

Авторизация: реализация общего обработчика watchfield, WebAsset с языковыми константами, адаптация публичного Tariffinfo и нейтрального Deliverypoints, dev-сборка, установка и браузерные E2E на joomla.local. Документация полей обновляется после успешных тестов. Публичный релиз 1.3.2 уже выпущен; новый dev-релиз на GitHub не публикуется.

Контракт: DOM-сканер `[data-watchfield]`; полные имена источников из Joomla Form, область — ближайшая форма; одна пара input/change обработчиков на источник; `joomla:updated` и повторяемые subform; удаление подписок и отмена запросов при удалении полей. Общие события `watchfield:loading`, `watchfield:data`, `watchfield:error`, `watchfield:empty` передают снимок именованных значений и данные. AJAX POST использует CSRF, отмену устаревших запросов и debounce; Script Options читаются через отдельный ключ и точечный путь. Отображение — отдельные ассеты тарифов и пунктов.

Инварианты: XML zip/city/fias_guid по наличию полностью отключает зависимости; POSTAMAT и пункты только выдачи доступны через фильтры; исходный Tariffinfo сохраняет type, watchfield и alias tariff_field, структуру layout; никакого JoomShopping-кода или inline исполняемого JS; stable ZIP 1.3.2 неизменен; действующие параметры и права стенда сохраняются; CDEK используется только для чтения справочников. Версия 1.4.0-dev: новые возможности обратно совместимы с опубликованной 1.3.2.

Проверки: PHP/Joomla 4–6 контракт API и формы; синтаксис и состав ZIP; нативная установка Joomla; Chrome DevTools Protocol, обычные формы и subform, разные источники данных, XML-приоритет, несколько потребителей, ошибки и гонки AJAX, языковые Script Options, реальные запросы справочников CDEK. Артефакты и ограничения сохраняются в отчёте.

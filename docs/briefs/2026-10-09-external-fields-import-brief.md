# Brief

## Task

Внешний импорт полей 2026-10-09 из проекта JoomShopping-WT-CDEK-shipping-method по прямому поручению оператора. Импорт выполняет агент исходного проекта, не агент библиотеки.

## Requested Outcome

Скопировать проверенные PHP/JS прототипы в проект библиотеки и оставить происхождение, точное состояние и задачи агенту библиотеки для отдельной подготовки релиза 2026-10-10.

## Problem Statement

Общий watchfield и поля ПВЗ/тарифа проверены в JoomShopping на joomla.local. Библиотечный агент должен видеть внешние изменения и не принимать прежнюю проверку интеграции JoomShopping за приёмку библиотеки.

## Stakeholders

Оператор, агент JoomShopping, агент WT-CDEK-Joomla-PHP-library.

## Constraints

Копирование без адаптации и перезаписи прежних файлов. Сохраняются donor namespace/type/asset paths/docblocks как происхождение прототипа. Релиз, установка, API-вызовы, изменение версии и commit/push сегодня не выполняются. Прежний .webtolk flow сохраняется; создание .pf/onboarding не входит в поручение.

## Inputs Provided

Последнее поручение: «скопируй туда поля в проект и запиши в историю проекта что нужно сделать для релиза завтра. Агент проекта библиотеки должен знать, что это внешнее вмешательство». Source evidence: .pf/artifacts/runs/cdek-fields-assets-20261009 исходного проекта.

## Assumptions

Сегодня передаётся полный комплект прототипа: три поля, общий PHP resolver и три JS. Поле статусов JoomShopping передаётся для полноты; его включение в универсальную библиотеку требует отдельного решения её агента.

## Success Criteria

Семь новых файлов совпадают с проверенными исходниками; прежние tracked files библиотеки не меняются; журнал, контекст и handoff явно маркируют external_intervention; приёмка библиотечного релиза остаётся pending.

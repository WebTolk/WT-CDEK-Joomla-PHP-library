# F3: Сохранить совместимость старых Tariffinfo overrides

Приоритет: **P2 / BC**. Статус: **Открыта**.

## Подтверждение

Исторический аудит публичной разметки; native AJAX fixtures не проверяют старые template overrides.

## Места в коде

- `lib_webtolk_wtcdek/layouts/fields/tariffinfo.php`
- `lib_webtolk_wtcdek/media/js/wtcdek-watchfield.js`
- `lib_webtolk_wtcdek/media/js/wtcdek-tariffinfo.js`

## Проблема

Прежние overrides выводят data-watch-field/data-tariffs; новый scanner ожидает data-watchfield. Старый layout остаётся пустым без JS exception.

## Требуемое изменение

Повторить публичный layout 1.3.2 без изменений на новой версии. Для minor-релиза предпочесть совместимый адаптер; изменение BC-политики согласовывать явно.

## Критерии приёмки

- [ ] Неизменённый старый override отображает и обновляет тариф.
- [ ] Новый default layout и новые возможности сохранены.
- [ ] Нет двойной регистрации/двойного render; сценарии покрыты браузером.

## Ограничения

Сохранить Joomla 4.2.7+ и PHP 7.4. Не запускать реальные запросы CDEK, менять стенд, выпускать ZIP/релиз или исправлять соседние задачи без отдельного scope. Этот файл — проектная задача; native PF ledger отсутствует, проект работает через .webtolk.

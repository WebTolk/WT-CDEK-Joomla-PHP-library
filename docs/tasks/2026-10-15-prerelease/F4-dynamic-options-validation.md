## Проблема

Стандартное validate=options видит server options (placeholder/saved), но не AJAX options; у grouped Tarifflist каталог также не совпадает с набором OptionsRule.

## Требуемое изменение

Определить правила валидации ПВЗ по адресу/фильтрам и тарифа по актуальному каталогу. Решить поддержку стандартного options и поведение при недоступном API. Не считать saved-code доказательством валидности.

## Критерии приёмки

- [ ] Новый допустимый ПВЗ и тариф проходят реальный submit на Joomla 4/5/6.
- [ ] Непринадлежащий адресу/фильтрам или неизвестный код отвергается.
- [ ] Недоступность API имеет явную политику и понятную ошибку.
- [ ] Отсутствие validate=options само по себе не объявляется уязвимостью; решение сохраняющего обработчика документировано.

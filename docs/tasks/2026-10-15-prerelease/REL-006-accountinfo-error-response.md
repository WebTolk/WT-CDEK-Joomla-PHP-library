# REL-006: Обрабатывать ошибочный ответ в AccountinfoField

Приоритет: **P2**. Статус: **Открыта**.

## Подтверждение

Подтверждено чтением исходника: незащищённый доступ к response[0]['code']. Реальный CDEK в аудите не вызывался.

## Места в коде

- `plg_system_wtcdek/src/Field/AccountinfoField.php:45`
- `plg_system_wtcdek/src/Field/AccountinfoField.php:46`

## Проблема

Пустой список или error envelope не содержит response[0]['code']. При открытии настроек возникают PHP notices/warnings вместо корректной обработки недоступного API.

## Требуемое изменение

Проверять тип/форму ответа и наличие ожидаемого кода; ошибки/пустой результат обрабатывать без чтения отсутствующих ключей. Сохранить текущее назначение поля; отдельное изменение способа проверки подключения не входит в эту задачу.

## Критерии приёмки

- [ ] Подставные успешный ответ, [], error envelope и неверная форма не дают PHP warnings.
- [ ] Индикатор успеха показывается только для подтверждённого ответа.
- [ ] Публичные параметры плагина и PHP 7.4 сохраняются.
